# ระบบจัดการวัสดุสำนักงาน (stockv2)

ระบบเบิก/รับเข้า/ติดตามสต็อกวัสดุ ใช้ Google Sheets เป็นฐานข้อมูล, Google Apps Script เป็น backend, และหน้าเว็บบน GitHub Pages

## ไฟล์ในชุดนี้
| ไฟล์ | ใช้ทำอะไร | ต้องแก้ไหม |
|---|---|---|
| `index.html` | หน้าเว็บทั้งหมด | ไม่แก้ (อัปเดตเวอร์ชันใหม่ = วางทับไฟล์นี้) |
| `config.js` | ค่าตั้งของแต่ละบริษัท (URL ของ API, ชื่อระบบ, ผู้จัดทำรายงาน) | **แก้ที่นี่ที่เดียว** |
| `code.gs` | backend (วางใน Google Apps Script) | แก้เฉพาะถ้าอยากเปลี่ยนค่าตั้งต้นในบล็อก `APP_CONFIG` ต้นไฟล์ |
| `Logo.png` | โลโก้ (ไม่ใส่ก็ได้) | เพิ่มเองถ้าต้องการ |

## ติดตั้งให้บริษัทใหม่

### 1) เตรียมชีทต้นแบบ (ทำครั้งเดียวต่อบริษัท)
- ทำสำเนาชีทต้นแบบ แล้ว**ล้างข้อมูลจริง**ให้เหลือเฉพาะหัวตารางกับสูตร
- ต้องมีแท็บ `สรุปรายงาน`, `รายการวัสดุ`, `รับเข้า`, `เบิก` (แท็บ `คำขอเบิก`, `ประวัติปรับยอด` ระบบสร้างให้เอง)

### 2) ติดตั้ง backend
1. เข้า [script.google.com](https://script.google.com) ด้วยบัญชีของบริษัท → New project
2. วางเนื้อหา `code.gs` ลงใน Code.gs
3. Deploy → New deployment → ประเภท **Web app** → Execute as: **Me** → Who has access: **Anyone**
4. กดอนุญาตสิทธิ์ แล้วคัดลอก URL ที่ลงท้าย `/exec`

### 3) ติดตั้งหน้าเว็บ
1. แก้ `config.js`: ใส่ URL `/exec` ใน `apiUrl` และปรับชื่อระบบ/ผู้จัดทำรายงาน
2. (ไม่บังคับ) วาง `Logo.png` ไว้ข้าง `index.html`
3. อัปโหลด `index.html`, `config.js` (และโลโก้) ขึ้น GitHub → Settings → Pages → เลือก branch `main` / root

### 4) ตั้งค่าครั้งแรกในหน้าเว็บ
1. เมนู → เข้าสู่ระบบแอดมิน: รหัสเริ่มต้นคือ `admin1234` ระบบบังคับให้เปลี่ยนทันที **ให้ทำก่อนแจกลิงก์ให้ใคร**
2. เมนู **จัดการคลัง** → ตั้งชีทต้นแบบ แล้ว "สร้างจากต้นแบบ" หรือ "เชื่อมชีทที่มีอยู่"
   (ชีทที่เชื่อมต้องแชร์ให้บัญชีเจ้าของระบบเป็น "ผู้แก้ไข" ชื่ออีเมลแสดงอยู่ในหน้านั้น)
3. เมนู **ตั้งค่า** → ใส่อีเมลรับแจ้งเตือน, LINE (ถ้าใช้), ลิงก์เว็บ

## อัปเดตเป็นเวอร์ชันใหม่
1. **Apps Script ก่อน**: วาง `code.gs` ใหม่ → Deploy → Manage deployments → ดินสอ → New version → Deploy (อย่ากด New deployment เพราะ URL จะเปลี่ยน)
2. **แล้วค่อยหน้าเว็บ**: อัปโหลด `index.html` ใหม่ทับ (ไม่ต้องแตะ `config.js`) แล้วกด Ctrl+Shift+R
3. ย้อนกลับ: เลือก Version เก่าใน Manage deployments / ย้อน commit ใน GitHub

## ข้อควรระวัง
- repo สาธารณะ (Public) ทุกคนเห็นไฟล์ `config.js` รวมถึง `apiUrl` และเห็นรหัสเริ่มต้น `admin1234` ในโค้ด ถ้าใช้จริงควรใช้ repo ส่วนตัวหรือโฮสต์ของบริษัทเอง และเปลี่ยนรหัสแอดมินทันที
- อย่า commit ข้อมูลจริง (ไฟล์ชีท, ชื่อพนักงาน, ID ชีท) ลง repo การลบไฟล์ทีหลังไม่ลบประวัติ
- ลบคลังไม่ได้ ใช้ "ซ่อน" แทน (ข้อมูลในชีทยังอยู่)
